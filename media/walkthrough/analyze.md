# Follow streams and see statistics

- **Follow TCP / UDP / TLS / HTTP Stream** (row menu): the conversation's
  data as ASCII, a hex dump or raw bytes.
- **PCAP Statistics**: conversations, endpoints, protocol hierarchy, I/O
  graph, expert information, flow graph and TCP stream graphs. Rows become
  filters with a click.
- **Export Objects**: files carried over HTTP, SMB, TFTP, IMF, DICOM and
  FTP-DATA.
- **Export**: the displayed, selected or marked packets to pcapng or pcap,
  the packet list as CSV or JSON, or full dissections.
- **Coloring rules**, **name resolution**, **TLS decryption** with a key log
  file, **Lua dissectors** and **Decode As** work like in Wireshark.

Every command is under **PCAP** in the Command Palette (`Ctrl+Shift+P`).
